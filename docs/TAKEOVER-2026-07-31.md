## 3. SECURITY — the findings that matter most

### 3b. The push gate on this branch HAS A LIVE HOLE (CRITICAL, fix in flight)

The gate landed in `782f2ba..802a937` can be bypassed by **one character of case**.
PROVEN end-to-end against a real bare remote with the gate as the actual pre-push hook:

```
git update-index --add --cacheinfo 100755,<blob>,adapters/claude-code/Hooks/injected.sh
```

(capital `H`) then commit and push → **rc=0, gate silent, lands on the remote** — and a
later clone materialises it at `adapters/claude-code/hooks/injected.sh`, inside the real
carrier directory alongside the genuine hooks, because the filesystem is case-insensitive.
Same for `Git-Hooks/pre-push`, `SCRIPTS/evil.sh`, `adapters/Claude-Code/hooks/evil.sh`,
`Manifest.json`.

`rrg_in_surface` (`hooks/lib/review-record-gate-lib.sh:138-211`) matches tree prefixes
case-sensitively; the surface it protects is realised case-insensitively. Only the
INJECTION direction is exploitable — clobber is not, because 0 of 311 in-surface canonical
paths contain an uppercase letter, so the real lowercase path always wins the checkout race.

**Do not treat this branch's gate as sound until that fix lands.** Unicode NFC/NFD on APFS
and Windows trailing dot/space are the same class and remain untested. Full row:
`SURFACE-PREDICATE-NARROWER-THAN-DELIVERY-IDENTITY-01` in `docs/backlog.md`.

## 7. Machine constraints that do NOT transfer

The Mac mini has `~/.claude/*` as SYMLINKS into `adapters/claude-code/`, so
`install.sh` must never run there. **A normal machine does not have this** — check
`ls -la ~/.claude/hooks | head` before assuming either way.

Portability floor is `/bin/bash` 3.2.57 (macOS). No `${v^}`, `${v,,}`, `declare -A`,
`mapfile`, `date -d`. Run suites on BOTH interpreters by ABSOLUTE PATH, sequentially,
and drive the script under test via `$BASH` — otherwise the 3.2 column tests only the
harness, never the script body. That defect was found twice today in shipped suites.

`zsh` is the interactive shell: `"$var:refs/..."` is parsed as `${var:r}` + `efs/...`.
Use `"${var}"`. This silently broke 10 branch pushes today.
